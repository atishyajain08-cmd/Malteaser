🚀 Malteaser Setup Guide

Complete your e-commerce storefront configuration in 5 simple steps

1 Supabase Project
2 Database Schema
3 Admin User
4 Configuration
5 Go Live

1
Create a Supabase Project

  1. Go to supabase.com and sign up for a free account
  2. Click "Create a new project"
  3. Choose a project name (e.g., "malteaser-store")
  4. Select a database password and region closest to your users
  5. Wait for the project to initialize (2-3 minutes)
  6. You'll land on the project dashboard
💡 Tip: Save your database password safely — you'll need it for backups

2
Create Database Tables

  1. In your Supabase project, go to SQL Editor (left sidebar)
  2. Click "New Query"
  3. Copy the SQL schema below and paste it:
-- Run this SQL in Supabase SQL Editor CREATE TABLE IF NOT EXISTS catalog_items ( id TEXT PRIMARY KEY, title TEXT NOT NULL, description TEXT, price NUMERIC NOT NULL, image_url TEXT, storage_path TEXT, section TEXT, label TEXT, is_active BOOLEAN DEFAULT true, sort_order SMALLINT, created_at TIMESTAMPTZ DEFAULT NOW(), updated_at TIMESTAMPTZ DEFAULT NOW() ); ALTER TABLE catalog_items ENABLE ROW LEVEL SECURITY; CREATE POLICY "Public read" ON catalog_items FOR SELECT USING (is_active = true); CREATE POLICY "Admin create" ON catalog_items FOR INSERT WITH CHECK (auth.jwt() ->> 'role' = 'authenticated'); CREATE POLICY "Admin update" ON catalog_items FOR UPDATE USING (auth.jwt() ->> 'role' = 'authenticated'); CREATE POLICY "Admin delete" ON catalog_items FOR DELETE USING (auth.jwt() ->> 'role' = 'authenticated');
  1. Click "Run" to execute the SQL
  2. You should see a success message
✓ Tables created successfully

3
Create Admin User

  1. Go to Authentication > Users in your Supabase project
  2. Click "Invite"
  3. Enter your email address
  4. Choose a strong password (8+ characters, mix of letters/numbers/symbols)
  5. Click "Send Invite"
⚠️ Important: This user will have full admin access. Keep credentials safe!

4
Configure Credentials

  1. In Supabase, go to Settings > API
  2. Copy your Project URL
  3. Copy your anon/public key (NOT the service role key)
  4. Open the file supabase-config.js in this project
  5. Replace the URL and key:
    window.MALTEASER_SUPABASE = { url: "https://YOUR_PROJECT_URL.supabase.co", anonKey: "YOUR_ANON_KEY" };
  6. Save the file and commit to git
⚠️ Never commit the service-role key! Only the public anon key is safe to commit.

5
Test & Go Live

  1. Run the Health Check to verify everything is connected
  2. Test the Admin Panel — sign in with your admin credentials
  3. Try adding a product (upload image + metadata)
  4. Visit the Homepage to see your product
  5. Push your changes to GitHub:
    git add . && git commit -m "Configure Supabase" && git push origin gh-pages
✓ Setup complete! Your store is now live
